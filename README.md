# Air Almaty

Интерактивный Flutter-прототип мобильного приложения о качестве воздуха в Алматы.
Дизайн перенесён из Figma (файл `J2tS95MvQaaeqoAamgjmgl`). Бэкенда нет: данные отдаёт
`MockAirRepository` с имитацией задержки сети, поэтому все экраны живые.

## Экраны

- **Карта** — средний AQI по городу, 8 районов на схеме, легенда, карточка «Мой район»,
  по тапу на район — карточка с PM2.5 / PM10 / NO₂ и советом.
- **Прогноз** — выбор района, «Сегодня / Завтра / 7 дней», график, мин/макс/среднее,
  подсказка «лучшее время для прогулки».
- **Причины** — пять причин смога и советы по защите.
- **Ещё** — мой район, уведомления, превью виджета, язык, единицы (US AQI / PM2.5),
  источники данных, о проекте, обратная связь, оценка.

## Запуск

```bash
flutter pub get
flutter run -d chrome   # или windows / android / ios
flutter test
```

## Структура

- `lib/theme` — цвета, шкала AQI (US EPA), тема Material 3, шрифт Inter.
- `lib/data` — модели и `AirRepository` (абстракция) + `MockAirRepository`.
- `lib/state` — `AppState` (provider).
- `lib/screens`, `lib/widgets` — экраны и переиспользуемые виджеты.

Чтобы подключить реальный бэкенд, реализуйте `AirRepository` и передайте его в `AirAlmatyApp`.

## Известные ограничения

- Язык: доступен только русский, казахский и английский помечены «скоро» (в дизайне нет переводов).
- В Figma для AQI 156 написано «Вредно для чувствительных» оранжевым, но по шкале 151–200
  это «Вредно» (красный) — в приложении использована шкала.
